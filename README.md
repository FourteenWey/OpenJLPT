# jlpt-vocab-scanner

本地运行的 JLPT N3 词汇快筛工具。用来快速测出你对 N3 词汇的真实记忆保留率，并筛出遗忘词。
React + TypeScript + Vite，数据存在浏览器 IndexedDB，不需要登录、服务器或任何在线接口。

## 启动

需要 Node.js 和 npm（开发与测试环境为 Node 26、npm 11，更低版本未验证）。

```bash
npm install
npm run dev        # 打开 http://127.0.0.1:5173/
```

其它命令：`npm test`（测试）、`npm run typecheck`、`npm run build` + `npm run preview`（生产构建预览）。
词表已随项目提交，日常运行不联网。`npm run fetch-data` 只在想重新下载词表时使用。

### 一键启动

```bash
./start.sh                  # 只启动本平台；已在运行的会跳过
./start.sh voicevox         # 可选：另外启动 VOICEVOX Engine（需已安装）
./start.sh all              # 两者都启动
./start.sh restart          # 重启本平台
./start.sh restart voicevox # 指定目标（app 默认 / voicevox / all）
./start.sh status           # 查看状态（全部在运行返回 0，否则返回 1）
./start.sh stop             # 停止
./start.sh logs             # 跟随日志（Ctrl-C 退出）
./start.sh --open           # 启动后用浏览器打开
```

- 已经手动启动过的服务也能识别：`start` 会跳过，`stop` / `restart` 会关掉它，但只处理确认属于本项目（vite）或 VOICEVOX 的进程，端口被别的程序占用时只报告、不动它。
- 进程号和日志在 `.run/`（已忽略提交）。本平台用 `vite --strictPort` 启动，5173 被占用时直接报错，不会悄悄换端口。
- 引擎自动查找 `/Applications/VOICEVOX.app` 和 `~/Applications/VOICEVOX.app`。装在别处时指定：`VOICEVOX_ENGINE=/path/to/run ./start.sh`（可以是 `run` 文件、它所在目录，或 `.app`）。
- 端口可用 `APP_PORT`、`VOICEVOX_PORT`（以及 `APP_HOST`、`VOICEVOX_HOST`）覆盖，默认 5173 和 50021。改了引擎端口还要同步改 `src/lib/ttsProviders.ts` 里的 `VOICEVOX_URL`。
- 引擎首次加载模型较慢，最多等 90 秒。只有目标包含 voicevox 且没找到引擎时才会提示安装，脚本返回非 0。

## 怎么用

1. 首次打开会自动载入 OpenJLPT N3 词表（1659 词）。「数据」页可再载入 N5–N3 累计词表（2963 词）或导入自己的 CSV/JSON。
2. 「快筛」页选词表，选「随机抽样」（样本量 + 可选种子）或「全量普查」，点开始。
3. 卡片显示词形。新建会话时默认勾选「词形下方显示例句」：翻卡前词形下方会出现一条日文例句，目标词用底色标出，用来判断多音词该读哪个音（如 末 在「考えた末」里读すえ）。先回忆，再按 Space 显示读音、释义、词性和例句译文，再评级，评级后自动跳到下一词。
   没有例句的词（N3 里约 40 个）只显示词形。取消勾选则翻卡前只显示词形。

| 键 | 作用 |
|---|---|
| Space | 显示答案并朗读读音；暂停时继续 |
| R | 重播日语发音（显示答案后） |
| A | 确定掌握：读音与词义都能独立回忆 |
| S | 模糊记得：只记得一部分，或需要联想 |
| D | 不认识：想不起来或记错 |
| Z / ⌘Z / Backspace | 撤销上一步（可连续撤销） |
| P | 暂停 / 继续（暂停时遮住词形，不计时） |
| G | 跳转到第 N 个（已评过的会落到其后最近的未评词） |
| H | 查看本次作答历史 |
| ? | 快捷键帮助 |

界面和统计里的等级叫 A / B / C，对应按键 A / S / D。未显示答案前按评级键无效。页面切到后台时计时自动暂停。
默认只用键盘即可完成全部操作，按钮点击后会自动失焦，不会被 Space 再次触发。

## 朗读

读音只用词表里的假名，不让引擎自行判断汉字读法。多音词在词表里是独立词条（如 人気 にんき / ひとけ），各读各的。没有云端调用，不上传学习数据。

- **系统 TTS（默认）**：浏览器 Web Speech API，只选已安装的本地日语声音（ja-JP）。没有本地日语声音时会报错，不会改用在线声音。
- **VOICEVOX（可选）**：顶栏「语音引擎」切到 VOICEVOX 后才会连接本机引擎（`http://127.0.0.1:50021`，可用 `./start.sh voicevox` 启动）。引擎不可用时自动回退系统 TTS，顶栏显示当前引擎；15 秒内不再重复连接。默认声音为 もち子さん（风格 id 20）；切到 VOICEVOX 后顶栏会出现「发音人」和「风格」下拉（列表取自本机引擎），选择保存在浏览器里。
- **MeloTTS**：只预留了 Provider 接口，未接入。
- **缓存**：VOICEVOX 音频按「词汇 ID、读音、音色、语速、重音」缓存在内存（最多 80 条），再次播放不请求引擎。系统 TTS 没有可缓存的音频。
- **交互**：卡片初始不显示读音。Space 翻面后显示假名、释义和「发音」按钮，并自动朗读一次；R 重播；顶栏切换 0.8x / 1.0x / 1.2x。朗读不影响 A/S/D 评分。顶栏「朗读：开/关」可整体关闭。
- **听音识词**：「听音」页只播放读音，翻面后看词形与释义再自评。成绩存在单独的设置项里，不进入视觉识词率与统计。
- **校正读音与重音**：翻面后点「校正读音」可改假名读法和重音位置（0=平板，n=第 n 拍后下降），保存在浏览器里。重音只在 VOICEVOX 生效。项目没有经过验证的重音数据，未手动指定的词一律显示「重音：待校验」，不会编造。
- 使用 VOICEVOX 音色及生成的音频，需遵守对应角色和音声的使用条款（もち子さん的规约见其官方页面）。引擎只接受 localhost / 127.0.0.1 来源，请用 `npm run dev` 或 `npm run preview` 打开。

## 数据来源与许可

词表来自 [evanclan/OpenJLPT](https://github.com/evanclan/OpenJLPT)（固定提交 `0d1d341`，数据 0.3.0）。
我检查过它的实际内容：

- 许可：数据与代码均为 **CC BY-SA 4.0**。上游是 Jonathan Waller 的 JLPT 词表（CC BY）、JMdict/KANJIDIC2（EDRDG，CC BY-SA 4.0）和 Tatoeba（CC BY 2.0 FR）。
- 字段：`id`（稳定 10 位十六进制）、`word`、`reading`、`meanings`（英文）、`pos`（JMdict 词性代码）、`level`、`jmdict_id`、`other_forms`、例句。
- **每个词只出现在列出它的最简单级别**，所以 `vocab/n3.json`（1659 词）是 N3-only，不含 N4/N5。N5 674 + N4 630 + N3 1659 = 2963 词，无重复 ID。
- 本项目保留词形、读音、释义、词性、级别，以及每词最多 1 条例句（不带注音，不含罗马字）。例句来自 Tatoeba（CC BY 2.0 FR），带句子 ID 供查看出处。
- 例句按词形匹配，多音词的句子读音可能与词条不同。`fetch-data` 会用 OpenJLPT 的例句注音核对；同一词形在 N5–N3 里有不同读音的词（如 今日 きょう/こんにち，共 20 个），只保留能确认读音一致的例句，其余不带例句。
- **上游没有中文释义**，内置词表的原始释义是英文（JMdict）。
- 为此项目另附了 N3 词的 **AI 生成中文释义**（`public/data/openjlpt-n3-zh.json`，1659 词）。它依据词形、读音、词性和英文释义写成，**未经人工校对**；卡片上带「AI 生成」标记，生成时没把握的词标「AI 生成 · 待核对」。N4/N5 词暂无中文。
- 导入你自己的词表（带 `meaning_zh` 列）后，匹配到的词显示你的中文释义，优先于 AI 生成的（见下）。
- 使用须保留署名并以相同方式共享，见 [NOTICE.md](NOTICE.md) 与 `third_party/OpenJLPT/`。应用「数据」页也显示署名。
- OpenJLPT 的级别是社区整理的非官方近似，官方没有公布考试词表。

## N3-only 与累计范围

两者是两个独立词表：各自抽样、各自统计，会话和统计页都带范围标签。同一个词在两个词表里共用同一条首评，所以先测 N3-only 再测累计时，N3 部分不会重复询问。
累计词表的统计页提供「按级别」拆分，N3、N4、N5 的结果分开看，不要混读。

## 导入自己的词表（如红宝书）

「数据」页导入 CSV 或 JSON。CSV 首行必须是表头，UTF-8 编码：

```csv
word,reading,meaning_zh,pos,level
挨拶,あいさつ,问候;打招呼,n; vs
ありがとう,,谢谢,exp
```

- 必填 `word`；汉字词必须有 `reading`，纯假名词可省略。
- 可选 `meaning`（英文）、`meaning_zh`、`pos`（JMdict 代码，用于词性与复合动词维度）、`level`、`id`、`example`（日文例句）、`example_translation`（例句译文）。也识别「单词/词形/读音/释义/中文释义/词性/例句」等表头。
- 去重：先按 `id`，再按「词形 + 读音」（NFKC 归一化）与已有词条匹配。匹配到的直接沿用，原有首评保留；文件内重复行跳过；缺词形或缺读音的行记为无效并在导入后列出。
- 已有词条缺中文释义时，会用导入文件补上。
- 导入时要选「样本框性质」：**完整词表**（词表就是你要估计的总体）或**人工挑选**（不做总体估计）。默认后者。

## 测量口径

- **首评**：每个词的第一次判断写入单独的 `baselines` 表，只能 `add`，不会被更新。之后的复习只写 `reviewItems` 与作答日志。已有首评的词在新会话中不再询问，沿用原评级。
- **撤销**：只在本会话内撤销最近一次评级，日志保留并标记已撤销，不参与统计。词一旦进入复习，就不能再撤销它的首评。
- **随机抽样**：词按 ID 排序后用带种子的 Fisher–Yates 洗牌（mulberry32），取前 n 个。同一词表 + 同一种子 = 同一样本。会话记录样本框（词表、词数、内容指纹）、样本量、种子与抽取时间。
- **置信区间**：只在「完整词表 + 随机抽样 + 已答完」时给出。95% Wilson 区间，按无放回抽样做有限总体校正（等效样本量 n(N−1)/(N−n)）。范围只限该样本框。
- **普查**：答完全部词后，比例就是该词表的实际值，不给区间；未答完不作估计。
- **人工挑选的词表**：不声称总体精度。
- **测试条件**：会话记录是否开了例句提示，统计页会显示。有例句时更容易想起词义，掌握率会比只看词形偏高，所以要和之前的结果比较，请保持同一设置。复习时始终显示例句。
- **两个指标分开**：「独立识词覆盖率」是首评 A 的占比；「复习后记忆保持率」只统计复习作答，二者不合并。
- **维度**：词性（名词 / する名词 / 动词 / い形容词 / な形容词 / 副词 / 其他）、假名词 / 汉字词、复合动词、JLPT 级别。复合动词按词形规则判断，没有形态分析器，纯假名书写的可能漏判。每类词数少于 10 时会标注。
- **耗时**：每词的有效用时（暂停、切后台、打开面板时不计），统计页给出总用时、平均和中位数。

## 错词复习

- 只有首评为 B / C 的词进入队列。到期日按 当天 / 次日 / 第3天 / 第7天 / 第14天 推进。
- 复习中 A 进入下一阶段，间隔是相邻阶段偏移之差（按时完成时恰为第 1/3/7/14 天）；通过第 14 天后毕业。
- B 或 C 都算答错：回到「当天」重测，计一次答错。
- 「错词」页显示首评、最近评级、阶段、下次复习日和答错次数。
- 「导出待复习错词为 Anki CSV」使用 Anki 2.1.54+ 的文件头（分隔符、HTML、Basic 笔记类型、第 1 列为 GUID、第 4 列为标签），重复导入会更新而不是新增。正面是词形，背面是读音、释义、词性。

## 备份与导出

- 「数据」页：完整 JSON 备份与恢复（恢复前会校验结构，确认后在一个事务里整体替换）。
- 「统计」页：本会话结果 CSV（每词首评、最近评级、复习状态）与全部作答日志 CSV。导出的 CSV 会给以 `= + - @` 开头的文本加前缀，防止 Excel 当作公式。
- 数据只保存在这台电脑的浏览器里。清除站点数据或换浏览器会丢失，请定期导出备份。

## 已知限制

- 例句是 Tatoeba 的句子，不是为词条量身写的：个别句子里的词读音或用法和词条不一致，翻卡后以答案面的读音为准；活用后的词只能高亮词干，找不到时不高亮。
- 中文释义是 AI 生成的，可能有错或不贴合你的教材，请以自己的词表为准。N4/N5 词没有中文释义。
- 同一浏览器里不要同时开两个标签页做同一个会话，两个页面都会响应按键。
- 复合动词与词性维度依赖 JMdict 词性代码，自定义词表没有 `pos` 时这些维度显示「未标注」。
